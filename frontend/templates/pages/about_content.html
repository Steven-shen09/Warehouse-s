项目简介

Warehouse-s 是一套全栈物品租借管理系统，旨在帮助团队或组织高效管理物品的借出、归还、审核与追踪。 系统围绕"申请 → 审核 → 借出 → 归还"这一核心流程，结合状态机引擎和RBAC 权限控制， 确保每次租借操作都被正确记录和追踪，避免物品丢失或超期未还。

核心功能
物品管理

物品 CRUD、多仓库库存分布、仓库级借出追踪、低库存预警、CSV/Excel 批量导入导出。

租借引擎

库存检查、数据库事务保护、部分归还支持，防止超租和并发冲突。

审核工作流

单级审核、超时检测与自动提醒、驳回后重新提交，确保租借合规。

状态机驱动

严格的状态流转：待审核 → 借出中 → 已归还 / 逾期，仅由明确事件触发变更。

RBAC 权限

admin / approver / user 三级角色隔离，细粒度控制页面访问和操作权限。

多仓库 + 仓库级追踪

5 大仓库独立管理库存，借出精确记录来源仓库，按仓库展示借出量/剩余量，调拨跨仓转移。

操作日志

完整审计追踪，记录申请、审核、归还全链路操作，便于排查和责任追溯。

适配器模式

可选 AI 审核（DeepSeek）、OSS 图片存储（阿里云）、SMS 通知（阿里云），未配置自动降级。

快速开始 
# 配置 PostgreSQL 连接（.env）
DATABASE_URL=postgresql+psycopg2://warehouse:warehouse123@localhost:5432/warehouse

pip install -r requirements.txt
python run.py

启动后访问 http://localhost:8000 即可使用。

预置账号： 管理员 admin / admin123 · 审核员 approver1 / 123456 · 普通用户 user1 / 123456
